# 11-ES6

This folder covers useful ES6 features and modern JavaScript syntax used in everyday development.

## Topics Covered

- Array Destructuring
- Object Destructuring
- Default Values in Destructuring
- Spread Syntax
- Rest Parameters
- Optional Chaining
- Nullish Coalescing
- ES Modules
- Named Exports and Imports
- Enhanced Object Literals
- Default Parameters
- `for...of` Loop

## Files

| File | Description |
|------|-------------|
| 01-Destructuring.js | Extracting values from arrays and objects |
| 02-SpreadAndRest.js | Copying and combining data using spread syntax and rest parameters |
| 03-OptionalChainingAndNullish.js | Safely accessing nested data and handling missing values |
| 04-productData.js | Exporting product data and reusable functions |
| 04-ModulePractice.js | Importing and using exported product data |
| 05-EnhancedObjectLiterals.js | Creating objects using modern property and method syntax |
| 06-DefaultParameters.js | Using default values in function parameters |
| 07-ForOfPractice.js | Processing order items with a `for...of` loop |

## Learning Outcome

After completing this folder, I will be able to:

- Extract values from arrays and objects using destructuring.
- Copy and combine arrays and objects using spread syntax.
- Collect multiple function arguments using rest parameters.
- Handle missing nested data with optional chaining.
- Provide fallback values using nullish coalescing.
- Organize JavaScript code into separate modules.
- Export and import reusable data and functions.
- Use enhanced object literal syntax.
- Apply default parameter values.
- Process iterable data using `for...of`.
- Write cleaner JavaScript for practical application scenarios.
