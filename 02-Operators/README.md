## Learning Outcome

After completing this folder, I can:

- Perform arithmetic calculations.
- Assign and update variable values.
- Compare values using comparison operators.
- Combine conditions using logical operators.
- Increase and decrease values using increment and decrement operators.
- Use the ternary operator for simple decisions.
- Understand basic unary operators.
- Understand operator precedence.
- Use the nullish coalescing operator for default values.
- Combine different operators in practical examples.
