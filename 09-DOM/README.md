# 09-DOM

This folder covers the Document Object Model (DOM) and how JavaScript interacts with HTML elements.

## Topics Covered

- What is the DOM?
- DOM Tree
- Selecting HTML Elements
- `getElementById()`
- `querySelector()`
- `querySelectorAll()`
- Reading Element Content
- Changing Text Content
- Changing HTML Content
- Changing Element Attributes
- Changing Styles
- `classList`
- Adding and Removing CSS Classes
- Creating DOM Elements
- Adding Elements to the Page
- Removing DOM Elements
- Dynamic DOM Rendering
- Rendering Array Data into HTML
- Practical DOM Manipulation

- Add, remove and toggle CSS classes.
- Create HTML elements dynamically.
- Add and remove elements from the page.
- Render JavaScript data dynamically into HTML.
- Work with arrays of objects and the DOM.
