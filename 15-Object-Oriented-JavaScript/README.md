# 15 - Object-Oriented JavaScript

This module focuses on Object-Oriented Programming (OOP) concepts in JavaScript. It covers how to organize code using objects, classes, inheritance, encapsulation, and other OOP principles.

## Topics Covered

1. Introduction to OOP
2. Constructor Functions
3. Classes and Objects
4. Constructors
5. Methods in Classes
6. The this Keyword
7. Encapsulation
8. Getters and Setters
9. Inheritance
10. Method Overriding
11. Polymorphism
12. Static Methods and Properties
13. Private Class Fields
14. Practical OOP Application

## Learning Outcomes

- Understand Object-Oriented Programming concepts.
- Create and work with JavaScript objects and classes.
- Use constructors and class methods.
- Understand the this keyword.
- Apply encapsulation using private fields.
- Implement inheritance and method overriding.
- Understand polymorphism.
- Use static methods and properties.
- Build practical applications using OOP concepts.

## Practical Use Cases

- Building reusable application components.
- Managing users, products, and orders.
- Organizing application logic.
- Creating maintainable JavaScript applications.
- Understanding object-oriented application architecture.

## Technologies Used

- JavaScript (ES6+)
- Node.js
