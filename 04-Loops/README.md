# 04-Loops

This folder covers the basic loops used in JavaScript.

## Topics Covered

- `for` Loop
- `while` Loop
- `do...while` Loop
- Loop Control with `break`
- Loop Control with `continue`
- Nested Loops
- Practical Loop Exercises

## Files

Files will be added as each topic is completed.

## Learning Outcome

After completing this folder, I will be able to:

- Repeat code using loops.
- Use `for` loops for repeated tasks.
- Use `while` loops when a condition controls repetition.
- Use `do...while` loops.
- Stop a loop using `break`.
- Skip an iteration using `continue`.
- Understand basic nested loops.
- Apply loops to simple real-world problems.
