# 04-Loops

This folder covers loops and loop control statements in JavaScript.

## Topics Covered

- `for` Loop
- `while` Loop
- `do...while` Loop
- `break` Statement
- `continue` Statement
- Nested Loops
- Practical Loop Exercises

## Learning Outcome

After completing this folder, I will be able to:

- Understand why loops are used in JavaScript.
- Use `for` loops for repeated tasks.
- Use `while` loops based on a condition.
- Use `do...while` loops when code needs to execute at least once.
- Stop a loop using `break`.
- Skip an iteration using `continue`.
- Understand basic nested loops.
- Apply loops to simple programming problems.
