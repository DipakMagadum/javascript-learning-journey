# 01-Basics

This folder covers the fundamentals of JavaScript.

## Topics Covered

- Introduction to JavaScript
- Comments
- Console Methods
- Variables
- `let`, `const`, and `var`
- Data Types
- `typeof` Operator
- Primitive Data Types
- Non-Primitive Data Types
- Type Conversion
- Type Coercion
- Template Literals
- User Input
- Strict Mode

## Learning Outcome

After completing this folder, I can:

- Write and run basic JavaScript programs.
- Declare and use variables.
- Understand common JavaScript data types.
- Check the type of a value using `typeof`.
- Understand primitive and non-primitive data types.
- Convert values between common data types.
- Understand basic type coercion.
- Use template literals for dynamic strings.
- Take basic user input in Node.js.
- Understand the purpose of strict mode.
