# 07-Objects

This folder covers JavaScript objects and practical object-based data handling.

## Topics Covered

- Object Fundamentals
- Object Properties and Values
- Dot Notation and Bracket Notation
- Adding, Updating and Deleting Properties
- Nested Objects
- Arrays of Objects
- Object Methods
- `this` Keyword with Objects
- Object Destructuring
- Object Spread
- `Object.keys()`
- `Object.values()`
- `Object.entries()`
- Practical Object Data Handling
- Combining Objects with Array Methods

## Files

| File | Description |

| 01-ObjectBasics.js | Creating objects and working with properties |

## Learning Outcome

After completing this folder, I will be able to:

- Create and work with JavaScript objects.
- Access, update, add and delete object properties.
- Work with nested objects.
- Handle arrays containing objects.
- Create methods inside objects.
- Understand the basic use of the `this` keyword with objects.
- Extract object properties using destructuring.
- Copy and combine objects using the spread operator.
- Inspect object data using common object utility methods.
- Combine objects with array methods for practical data handling.
- Work with data structures commonly returned by APIs.
