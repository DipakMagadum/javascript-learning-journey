# 06-Arrays

This folder covers arrays and the most commonly used array operations in JavaScript.

## Topics Covered

- Array Fundamentals
- Array Indexing
- Updating Array Elements
- Array Length
- Adding and Removing Elements
- Common Array Methods
- Array Iteration
- `for...of`
- `forEach()`
- `map()`
- `filter()`
- `reduce()`
- `find()`
- `findIndex()`
- `some()`
- `every()`
- Practical Array Data Handling

## Files

| File | Description |

| 01-ArrayBasics.js | Creating arrays and working with basic array data |
| 02-ArrayIndex.js | Accessing array elements using indexes |

## Learning Outcome

After completing this folder, I will be able to:

- Create and work with arrays in JavaScript.
- Access and update array elements.
- Add and remove elements from arrays.
- Use commonly used array methods.
- Iterate through arrays using different approaches.
- Transform data using `map()`.
- Filter data using `filter()`.
- Calculate values using `reduce()`.
- Search for data using `find()` and `findIndex()`.
- Validate array data using `some()` and `every()`.
- Work with arrays containing objects.
- Apply array concepts to real-world data.
