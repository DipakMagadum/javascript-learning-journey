# 10-Events

This folder covers JavaScript events and how to handle user interactions on a webpage.

## Topics Covered

- JavaScript Events
- `addEventListener()`
- Mouse Events
- Keyboard Events
- `input` and `change` Events
- Form Submit Events
- Event Object
- `event.target`
- `event.type`
- `event.key`
- `preventDefault()`
- Event Bubbling
- Event Delegation
- `stopPropagation()`
- Live Form Validation
- Practical Event Handling

## Learning Outcome

After completing this folder, I will be able to:

- Handle user interactions using JavaScript events.
- Register event listeners with `addEventListener()`.
- Handle mouse and keyboard events.
- Respond to changes in input fields.
- Handle form submissions.
- Read information from the event object.
- Prevent default browser behaviour.
- Understand event bubbling and event delegation.
- Stop event propagation when needed.
- Perform basic client-side form validation.
- Build interactive browser-based interfaces.
